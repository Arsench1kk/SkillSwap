# SkillSwap Context Index

Read this folder before proposing architecture or writing code.

## Current truth

SkillSwap is a pre-MVP peer-to-peer learning project for university students in Almaty and Astana. The immediate goal is not to launch a marketplace. The immediate goal is to validate whether unfamiliar mentors accept structured requests and whether real learners complete useful sessions.
