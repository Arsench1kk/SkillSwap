# Release checklist

Собирает D6. Каждый пункт закрывается **фактом**: коммит/PR, команда и
результат, дата, кто проверил. Владельцы фич закрывают свои ошибки. Зелёные
тесты не означают решения о запуске: запуск утверждает команда после этого
списка и пробы с пользователями. Статусы: ✅ проверено · 🟡 частично ·
⛔ заблокировано · ⬜ не начато.

Последнее обновление: 16.11.2026, D6. Проверки ниже выполнены локально
(Docker Postgres 17, `CI=true`, отдельная БД `skillswap_test`) на стеке веток
D6 поверх `main` `edf8135`; GitHub CI на них ещё не наблюдался, пока PR не открыты.
