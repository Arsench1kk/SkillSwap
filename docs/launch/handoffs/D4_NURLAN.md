## D4-R07-P01 — варианты lifecycle для решения командой

**Статус: предложение, НЕ утверждённая спецификация.** Не разрешает реализацию
новых экранов, полей, событий или token-модели. Адресаты: D1/D2/D3/D5/D6 и владелец
продукта. Подготовлено D4 14 ноября 2026; передача через PR №9. Следующий шаг D4 —
получить ответы команды; D6 затем фиксирует выбранное в UX, D1 публикует контракт.

Уже заданные ограничения: ручное решение оператора, согласие обеих сторон,
одна session на match, создание в caller transaction confirm, контакты только
после взаимного подтверждения, оценки не публичны. Эти пункты не предлагаются
к повторному утверждению. Клик Meet не доказывает присутствие/завершение; passage
of time не создаёт completed/no_show.
